# Python OOP and Data Structures

A collection of Python programs demonstrating Object-Oriented Programming (OOP), fundamental data structures, and basic algorithms. This project is designed to strengthen programming fundamentals and problem-solving skills.

## Objectives

- Understand and implement OOP concepts in Python.
- Practice fundamental data structures.
- Implement basic searching and sorting algorithms.
- Improve logical thinking and problem-solving skills.
- Build a foundation for software engineering.

## Technologies Used

- Python 3
- Visual Studio Code
- Git and GitHub

## Topics Covered

### 1. Object-Oriented Programming (OOP)

- Classes and Objects
- Constructors and Methods
- Inheritance
- Encapsulation

### 2. Data Structures

- Stack using Python lists
- Queue using collections.deque
- Dictionary for frequency counting

### 3. Algorithms

- Binary Search
- Bubble Sort


## Learning Outcomes

- Applied Python programming fundamentals through practical examples.
- Practiced object-oriented programming concepts.
- Implemented and understood common data structures.
- Developed basic searching and sorting algorithms.
- Gained experience organizing and maintaining code using GitHub.
